# Mobile_Enderchest
Minecraft Java Datapack

Little Manual:

- After installation:
- - No inizialization needed, data pack have an auto inizialization

- Give item for set ender chest: 
- - /function x_me_moblile_enderchest:give_item

- Run:
- - Rightclick with this item in weapon mainhand and when at the setpoint is air, then the ender chest will be set.
- - On move, the ender chest will be remove
